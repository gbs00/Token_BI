## RM-01 安装后的菜单栏引导

状态：1.2.1 已实施，实机长期验收保留。

目标：避免用户安装并打开 App 后，因为没有桌面窗口而误以为启动失败。

- 首次运行时提供轻量提示，告知 Token BI 常驻 Mac 顶部菜单栏，并说明点击图标可查看额度、扫码连接副屏。
- 不恢复旧大控制台，不引入阻塞启动的独立启动页；正常使用时不反复打扰用户。
- 使用菜单栏附近的独立轻提示，确认/关闭/打开主面板时记住完成状态；老用户未完成过引导时也提示一次。

建议验收：首次运行能够找到菜单栏入口；确认提示后再次启动不重复展示；后台启动、账号同步和扫码功能不受影响。

## RM-02 代码精简与安装包瘦身

状态：1.2.1 完成第一批有依据的删减；持续审查列入后续版本。

目标：持续删除冗余或无效代码，降低维护成本，并针对实际打包内容减少安装包体积。

- 检阅调用关系与实际构建产物，识别无调用函数、重复包装、废弃分支、无效测试、未使用依赖及重复资源。
- 区分源码清理与包体优化：未进入安装包的测试或文档，删除后不会直接减少 DMG 体积。
- 重点评估旧控制台兼容入口、未启用功能依赖，以及 control/backend 运行时的重复内容；它们是候选项，不预先认定可以删除。
- 保留有效的账号一致性、权限、进程所有权、同步恢复及跨设备布局回归；不以删测试数量作为优化目标。
- 对比相同构建条件下的 DMG 体积、安装后体积、启动耗时及常驻资源占用；先建立基准，再确认具体目标。

建议验收：删减项有引用与打包分析依据；回归及正式包验证通过；账号优先级、菜单栏、扫码与副屏功能不退化；记录包体变化，性能结果不作未经测量的推断。

参考基线：1.2.0 发布 DMG 为 68,186,865 字节，约 65 MiB；安装体积、启动与常驻资源基准待测。

## RM-03 应用内更新

状态：1.2.1 已接通 Rust Updater 与签名制品流程；完整原生重启及副屏恢复仍需用户实机验收。

- 接入 Tauri 官方 Updater，设置中提供“检查更新”；有更新时变为“立即更新”。
- 后台联网检测到更新时，底部设置显示小红点，不主动打断用户。
- 支持查看说明、应用内下载、用户确认后安装重启，以及失败重试。
- 完整签名更新包与版本清单随 GitHub Release 发布；已有 1.2.0 用户需手动安装一次启用更新功能的版本。
- 与首次引导、代码精简的具体范围和验收标准统一见 [1.2.1 需求](PRD_v1.2.1.md)。
