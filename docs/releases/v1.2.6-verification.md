## 安装包体积

单位为字节，App 统计排除符号链接重复计数；MB 使用十进制。App 基线为本机已安装的动态内环 1.2.5，DMG/更新归档基线为 GitHub 已发布的 v1.2.5 附件，两者分别比较。

| 项目 | 1.2.5 | 1.2.6 | 减少 |
| --- | ---: | ---: | ---: |
| App | 184,569,474 | 54,739,074 | 70.3% |
| DMG | 62,854,710 | 22,993,196 | 63.4% |
| 更新归档 | 63,794,138 | 22,720,100 | 64.4% |

最终包的 native 主程序为 20,272,288 字节，control 为 11,244,290，backend 为 21,312,288，新增 Web Session 为 1,053,113，其余为图标/资源/签名。最大收益来自删除随 Playwright 分发的 Node 与浏览器自动化运行库，不是删除测试、文档或用户账号数据。

构建校验确认无生产 Playwright/Node、无旧控制台资源、framework 链接完整；App 预算收紧为 100 MB。Chrome/Probe 的历史登录配置未自动删除。

## 启动测量

同机、各五次、独立数据目录、暂停账号采集，运行打包 control/backend。构建与测试停止后测量。脚本：`scripts/benchmark_bundle.py`；本地原始结果：`dist/performance-v1.2.6/before.json`、`after.json`。

| 五次中位数 | 1.2.5 | 1.2.6 |
| --- | ---: | ---: |
| control 就绪 | 130.46 ms | 116.62 ms |
| backend 启动至状态确认 | 533.00 ms | 548.25 ms |
| 两个服务合计就绪 | 670.91 ms | 653.36 ms |
| 两个服务 RSS 合计 | 88,522,752 bytes | 84,885,504 bytes |
| 服务进程数量 | 2 | 2 |

合计耗时约减少 2.6%，五次样本范围重叠；backend 分项并未变快，不能认定具有稳定、显著的整体启动收益。该基准不包含 Tauri 面板首次绘制、官方请求、登录或 WebKit 网页进程，也不是清空系统文件缓存后的冷启动。

原生产逻辑已避免 OAuth 正常时预启动 Chrome，所以本次最明确收益是下载/安装体积和不再要求 Chrome，而非 OAuth 主链路突然提速。WKWebView 复用系统框架仍需占用运行内存；不能由安装包下降推算网页登录速度、常驻内存或耗电改善。
