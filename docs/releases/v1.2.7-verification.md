# v1.2.7 发布前验证

日期：2026-10-02（Asia/Shanghai）。发布范围为账号恢复、轻量额度轮询、日志保留和工程回归；不直接替换本机应用，用户从 1.2.6 设置页确认更新后安装并重启。

## 本地验证

- Python 3.9.6，开发/构建依赖见 [版本快照](v1.2.7-python.txt)，无新增生产依赖。
- 完整 Python/浏览器/原生组件回归 521 项通过，耗时 179.11 秒；JavaScript 13 项、Rust 28 项通过，另有 1 项显式视觉导出测试默认忽略。
- 依赖检查、Rust 格式与 Clippy `-D warnings` 通过；App 深度签名、DMG 校验及只读挂载通过，挂载包的版本、最低系统和主程序与构建产物一致。
- `release_local.sh` 完成回归及构建后，新加的离线重登验收断言错误地要求成功返回；实际接口应返回失败并保留旧额度。修正测试断言后，独立重新执行完整冻结服务检查，再制备更新附件并执行官方 Updater 测试。没有为了通过测试改动产品的失败语义。
- 冻结 control/backend 的健康、版本、暂停接入、网页资源、二维码、轻量状态和端口释放通过；轻量返回不包含地址和日志字段。
- 隔离 OAuth 请求、断网保留缓存、同账号失败重登保留额度及最后成功时间、网络恢复和退出通过。退出不修改外部授权文件。
- 官方 Tauri Updater 使用 1.2.6 版本上下文，发现 1.2.7、下载并验证原密钥签名、拒绝篡改，再安装到临时 App；1 项通过，耗时 1.32 秒。没有安装到 `/Applications`，没有关闭生产 HTTPS 或签名校验。
- 随后的子进程诊断改动仅作用于测试；相关 13 项再次通过，耗时 11.73 秒，完整 521 项再次通过，耗时 180.87 秒。自有隔离子进程的 macOS 堆栈采集另行验证成功。

## 包体与性能边界

App 为 40,185,898 字节，104 个实体文件、4 个符号链接，最低 macOS 11.0。原生代码 16,862,608 字节、共享运行库 21,432,544 字节、网页登录组件 1,053,113 字节；无生产 Playwright/Node、测试包或旧双运行库。

相较 1.2.6，App 增加 43,616 字节（约 0.11%），DMG 增加 42,165 字节（约 0.24%），仍低于 50MB App 预算。轮询路径不再读取日志或执行地址查询，但本轮没有新做整机冷启动、内存、耗电基准，不能据此宣称整体按比例提速。
