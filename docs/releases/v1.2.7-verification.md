# v1.2.7 发布前验证

日期：2026-10-02（Asia/Shanghai）。发布范围为账号恢复、轻量额度轮询、日志保留和工程回归；不直接替换本机应用，用户从 1.2.6 设置页确认更新后安装并重启。

反向 DNS 修复后已完整重新构建，并通过冻结服务及原密钥签名归档验证；以下附件为最终暂存文件，不使用修复前的首轮制品。

## 本地验证

- Python 3.9.6，开发/构建依赖见 [版本快照](v1.2.7-python.txt)，无新增生产依赖。Rust 为 1.95.0，仓库与 CI 固定同一工具链，包含 rustfmt / Clippy。
- 最终完整 Python/浏览器/原生组件回归 522 项通过，耗时 184.85 秒；JavaScript 13 项、Rust 28 项通过，另有 1 项显式视觉导出测试默认忽略。
- 依赖检查、Rust 格式与 Clippy `-D warnings` 通过；App 深度签名、DMG 校验及只读挂载通过，挂载包的版本、最低系统和主程序与构建产物一致。
- 首轮新加的离线重登验收断言错误地要求成功返回；实际接口应返回失败并保留旧额度。修正测试断言后，最终 `release_local.sh` 全流程以 0 退出，包含完整回归、构建、冻结检查和签名 Updater 测试。没有为了通过测试改动产品的失败语义。
- 冻结 control/backend 的健康、版本、暂停接入、网页资源、二维码、轻量状态和端口释放通过；轻量返回不包含地址和日志字段。
- 隔离 OAuth 请求、断网保留缓存、同账号失败重登保留额度及最后成功时间、网络恢复和退出通过。退出不修改外部授权文件。
- 官方 Tauri Updater 使用 1.2.6 版本上下文，发现 1.2.7、下载并验证原密钥签名、拒绝篡改，再安装到临时 App；1 项通过，耗时 1.25 秒。没有安装到 `/Applications`，没有关闭生产 HTTPS 或签名校验。
- 随后的子进程诊断改动仅作用于测试；相关 13 项再次通过，耗时 11.73 秒，完整 521 项再次通过，耗时 180.87 秒。自有隔离子进程的 macOS 堆栈采集另行验证成功。
- 禁止反向 DNS 的回归在旧实现失败，修复后相关 56 项通过（14.30 秒）。本地 HTTP 服务以实际绑定地址保留名称及分配端口，不改变线程、访问权限或监听范围；预览入口改为模块启动以共用实现，不导入生产容器。

## 包体与性能边界

App 为 40,186,138 字节，104 个实体文件、4 个符号链接，最低 macOS 11.0。原生代码 16,862,608 字节、共享运行库 21,432,784 字节、网页登录组件 1,053,113 字节；无生产 Playwright/Node、测试包或旧双运行库。

相较 1.2.6，App 增加 43,856 字节（约 0.11%），DMG 增加 42,361 字节（约 0.24%），仍低于 50MB App 预算。轮询路径不再读取日志或执行地址查询，但本轮没有新做整机冷启动、内存、耗电基准，不能据此宣称整体按比例提速。

## 远端回归

- 首次工作流解析失败已修正：任务级环境变量不引用 `runner.temp`，改为执行步骤写入隔离目录。
- 两次远端执行均为 519 项通过、2 项源码子进程就绪超时；第二次已限制单次健康探测并对齐 30 秒等待，仍未解决。没有跳过测试或把超时伪报为通过。
- [诊断执行](https://github.com/gbs00/Token_BI/actions/runs/36948407623) 为 519 项通过、2 项失败（414.35 秒）。两个子进程均停在 `socket_gethostbyaddr → mdns_hostbyaddr → _mdns_search_ex`；标准库 `HTTPServer.server_bind` 对绑定地址调用 `socket.getfqdn`，阻塞监听初始化。
- 控制服务和预览共用免反向 DNS 的 HTTPServer，相关隔离 fixture 同样复用；没有改动全局 DNS 函数、跳过测试、延长生产超时或变更网络权限。源码层面回归证明不再调用反向 DNS，但不将该远端问题当作历史本机启动慢的唯一原因。
- [DNS 修复后的执行](https://github.com/gbs00/Token_BI/actions/runs/36949438642) 中，522 项 Python/浏览器/原生回归通过（208.39 秒），13 项 JS、28 项 Rust 测试通过。Clippy 阶段失败来自自动安装的 Rust 1.99 新增 `chunks_exact_to_as_chunks` 风格规则，与本机已验收的 1.95 不一致；不属于功能测试失败。
- 固定本地及 CI 为已验证的 1.95.0，不禁用 lint 或降低 `-D warnings` 门禁；工具链升级需单独验收，固定后的远端结果发布前回读。
- 独立 Checks 不使用更新私钥或上传制品；旧 Release 工作流仍停用。
