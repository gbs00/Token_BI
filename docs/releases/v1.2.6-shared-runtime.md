# v1.2.6 共享运行库精简验证

日期：2026-09-25。本记录描述精简构建及本机安装验证；同日后续已正式发布 1.2.6，见[发布回执](v1.2.6-release.md)。`/Applications/Token BI.app` 与正式发布使用同一精简制品。[首轮 WKWebView 验证记录](v1.2.6-verification.md)保留精简前的体积与测试基线。

## 变更范围

- Rust 发布构建和控制启动器裁剪符号表；不改变优化等级、异常处理、UI 或业务流程。
- 排除 HTTPX 可选命令行入口及其 Pygments 依赖，保留实际 HTTP 客户端；该项单独重建后，后端入口减少 1,414,192 字节。
- 删除两个独立 spec，统一使用 `token-bi.spec` 和共享 `COLLECT`。两个服务入口各自保留模块归档，共用 `Resources/token-bi-runtime/_internal` 中的一套 Python、标准库与扩展库。进程职责、按需启动及账号数据位置不变。
- 启动器统一定位完整运行目录，不再分别查找两套运行库；更新解压后不能保留旧目录。
- 保留现有图标、证书、Unicode 支持及原生网页登录组件。不涉及系统 Python、启动解压或功能裁减。

## 验证结果

- `scripts/release_local.sh` 完整通过：Python/网页/原生 WKWebView 488 项，JavaScript 13 项，Rust 28 项；1 项显式视觉导出测试仍默认忽略。依赖、格式及 Clippy 检查通过。
- 正式打包启动器拉起共享运行库，验证控制服务、额度服务、页面资源、二维码、退出和端口释放。
- 冻结后的 HTTPX 使用隔离 OAuth 文件和本机 HTTP fixture 完成请求，校验 77% 额度；上游 503 时保留原额度及成功时间，恢复后重新同步，退出不改写外部授权文件。测试不读取或修改真实账号。
- 官方 Updater 的真实签名归档下载、验签、篡改拒绝、临时 App 安装通过；预置的旧双运行库目录安装后消失，新目录及 Python 链接完整。
- 主 App、嵌套原生组件签名、DMG 校验通过；只读挂载后的全部文件及符号链接与被测 App 一致，随后卸载挂载点。
- 构建验证阶段没有修改本机应用；随后按用户明确要求安装，结果见下节。
- 2026-09-25 发布前复跑同一精简包：488 项 Python/网页/原生 WebKit 测试（167.94 秒）、13 项 JS、28 项 Rust，以及依赖、格式、Clippy 和打包服务验证再次通过；未重建或更换本机已验收的二进制。
