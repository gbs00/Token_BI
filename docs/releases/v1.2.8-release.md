## 本机 1.2.7 → 1.2.8

1. 从 `/Applications/Token BI.app` 的设置页点击“检查更新”，看到“发现新版本 1.2.8”。
2. 点击“立即更新”，由应用从正式 GitHub Release 下载；界面确认“更新已准备好”“安装包已通过签名校验”。
3. 点击“重启完成更新”，由 Tauri Updater 安装并自动重启；未使用手工复制覆盖 App 的方式代替应用内更新。
4. 设置页显示 1.2.8 和“已是最新版本”；App plist 与后端健康接口均为 1.2.8，服务健康、账号接入启用。
5. 与升级前内存中的身份摘要对比为同一账号，无需重新登录；真实 OAuth 额度及存储重置到期明细正常返回，新明细标记为非旧记录。验收过程未手动读取、导出或上传令牌与 Cookie，应用自身继续按既有授权链路请求官方额度。
6. 深度签名校验通过；所有实体文件哈希及符号链接目标与发布构建逐项一致，主程序 SHA-256 为 `a17900da5c3a56d3c09d0c877e2143c5471502537fbba364708d4b9c2ec59043`。
7. 旧 App、control、backend 与原网页登录子进程均已退出；新实例仅有 shell、control、backend，未额外启动网页登录进程。
8. 原生面板正常显示额度与逐项重置时间，无重叠；扫码二维码生成正常，本机通过局域网地址读取看板返回 HTTP 200。

这里的“热更新”是应用内下载、签名校验、安装并重启，不是进程不停机的代码替换。更新期间副屏可能短暂断连；本轮没有在真实手机上验收重连，不能把本机 HTTP 成功等同于跨设备结果。
