# Token BI v1.2.1

## 本次更新

- 首次打开时在 macOS 菜单栏附近显示“我在这里哦”，帮助找到额度与扫码副屏入口。确认或打开面板后不再重复提示。
- 设置新增应用内更新：手动检查、更新说明、下载进度、失败重试，以及确认后安装重启。
- 后台非阻塞检查更新；发现新版本时设置显示小红点，不自动打开面板或强制重启。
- 删除固定面板开关和图钉。切换到桌面或其他窗口后自动收起，额度服务和已开始的下载继续运行。
- 清理未使用的前端 API 依赖及图标，打包排除未使用的 uvloop/watchfiles，保留 OAuth、CLI 与浏览器登录兜底和有效回归测试。

## 升级方式

1. 1.2.0 及更早版本需要手动安装本次 DMG 一次，将 Token BI.app 放入可写的应用程序目录。
2. 此后在设置中检查更新，或等待后台检查提示。点击“立即更新”下载，校验通过后点击“重启完成更新”。
3. 重启期间副屏会短暂断连。用户数据和账号偏好保存在应用包之外，不随更新包替换。

## 分发范围与说明

- 提供 macOS Apple Silicon DMG、Tauri 签名更新包、签名文件、latest.json 和 SHA256SUMS。
- 当前仍为 ad-hoc 应用签名，未进行 Apple Developer ID 签名及公证。Updater 签名用于验证更新包来源，不代替 Gatekeeper 信任。
- 本轮不更改额度计算、数据源优先级、看板横竖屏布局或局域网入口。
- 检查/下载需要能够连接 GitHub；仅推送源码不会让客户端获得更新，需要发布完整 Release 资源。
