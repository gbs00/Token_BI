# Token BI v1.2.4

## 本次更新

- **存储重置**：在菜单栏额度下方显示每次存储重置的剩余到期时间，按先后排列，不重复显示总次数。标题及无障碍名称统一为“存储重置”。
- **准确区分数据状态**：过期条目自动消失；没有可用重置、数据源不支持、明细不全分别处理，不把未知数据误报为零。只读展示，不提供兑换或消耗重置的操作。
- **保持额度获取稳定**：沿用 OAuth 优先，同一登录态读取到期明细；补充请求最多等待 2 秒，失败或字段异常不影响正常额度。CLI 不为此额外启动进程，缓存和退出继续保持账号隔离。
- **精简安装包与历史代码**：保留 Python framework 符号链接，避免重复打包，App 从约 200.4MB 降至 188.7MB；移除已退役的旧网页控制台、专属接口、打开脚本和无调用函数。新增运行库完整性和 195MB 包体预算验证。
- **开发产物保留规则**：清理工具默认只预览，显式执行才清理确认闲置的开发浏览器配置、过期备份和旧构建目录；保留有效账号数据、最新备份与当前构建缓存，不在用户 App 内自动执行。

菜单栏交互、扫码连接副屏、Web 看板和 OAuth > CLI > Web 优先级不变。本次继续保留 Playwright 网页登录兜底；CDP 评估选型与重构安排在后续版本，无新增运行依赖或账号数据迁移。

## 升级方式

1. v1.2.1 及以上用户：打开菜单栏面板的「设置」，检查更新，下载后确认「重启完成更新」。
2. 旧版本或需要手动安装：下载 DMG，退出旧 App 后替换应用程序目录中的 Token BI.app。
3. 升级保留账号和设置，重启期间副屏连接会短暂中断。

## 验证结果

- Python/Chromium/WebKit 全量 425 项、JavaScript 13 项、Rust 19 项及真实签名更新归档测试 1 项通过；格式、Clippy 与依赖检查通过。
- 311px 单/双额度布局、过期自动隐藏、零次/未知区分、账号退出隔离和异常明细回归通过。真实 OAuth 只读获取也已核对计数、到期时区及同一登录态，没有消耗任何重置。
- 完整重建 shell、control、backend；打包态健康、扫码、看板资源及停止后端口释放通过。App 深度签名、DMG 只读挂载、归档符号链接与 Updater 签名校验、篡改拒绝、临时 App 安装通过。
- 本轮发布不自动替换本机正在使用的 App，安装测试不修改真实账号或设置。

## 分发与边界

- 提供 Apple Silicon DMG、原密钥签名的 Updater 归档、`.sig`、`latest.json` 和 `SHA256SUMS`。
- App 仍使用 ad hoc 签名，未做 Apple Developer ID 签名或公证；Updater 签名不代替 Gatekeeper 信任。
- 仅新增菜单栏存储重置信息，不改变副屏布局。macOS 完整跨版本重启、真实网页登录、iPhone 真机及长期睡眠恢复仍需独立验收。
