# Token BI v1.2.6

## 原生网页登录

- 网页登录兜底改用系统 WKWebView，不再要求安装 Chrome，也不再随 App 携带 Playwright/Node。
- 继续优先读取本机 Codex OAuth，其次 CLI RPC，最后使用同账号网页会话。网页登录组件按需启动，不在正常 OAuth 同步时预加载。
- 退出账号只断开 Token BI 接入，不退出 Codex、CLI 或官方网站，不删除它们的登录凭据。
- 令牌失效最多重取一次；断网保留上次成功数据，限流遵守冷却，睡眠后按既有 180 秒频率继续同步，不补发遗漏请求。
- 网站会话由专用 WebKit 存储维护；Token/Cookie 不传到 Python、日志或局域网看板。不同账号结果不混用。

## 菜单栏额度图标

- 内环随剩余额度同步变化，100% 满环，0% 空环。
- 优先显示 5h 额度，没有时采用周额度；未知数据不显示成 0%。

## 安装包精简

- 控制服务与额度服务共用一套 Python 运行库，保留独立进程和原有按需启动行为。
- 裁剪发布程序符号表，排除未使用的 HTTPX 命令行和代码高亮依赖，不改变额度请求逻辑。
- 构建自动检查公共运行库不重复、必要模块完整，并验证旧目录不会残留在更新后的 App 中。

## 体积与验证

相较正式 v1.2.5，按实体文件统计，符号链接不重复计入，MB 为十进制：

| 制品 | v1.2.5 | v1.2.6 | 减少 |
| --- | ---: | ---: | ---: |
| App | 184.51 MB | 40.14 MB | 78.2% |
| DMG | 62.85 MB | 17.83 MB | 71.6% |

- 正式 WKWebView 组件已实机完成用户登录、成功后自动收起、同账号隐藏读取、连续读取和进程重启后的会话恢复，能取得额度及存储重置明细。
- 共享运行库精简前后，两个服务的隔离启动基准基本持平；包体缩小不等于整体启动、内存或耗电按相同比例改善。
- 断网、限流、401 单次恢复及睡眠调度由隔离测试覆盖；旧 macOS、第三方 SSO、长期会话过期和跨设备真实网络切换仍需扩大验收。

## 升级说明

- macOS 11 及以上，Apple Silicon；本版本仍为 ad hoc 签名、未公证。
- 旧 Chrome 登录态不会导入或删除。首次需要网页兜底时，在新的 Token BI 登录窗口手动登录一次；OAuth/CLI 正常用户不受影响。
- 继续提供 DMG 和使用原密钥签名的应用内更新归档。现有 1.2.1+ 用户可在设置中检查并确认更新。
- 官方网页内部接口可能变化；当前真实账号验证不能覆盖所有第三方 SSO 或组织账号。完整安装包体积和同条件启动基准见发布回执。
