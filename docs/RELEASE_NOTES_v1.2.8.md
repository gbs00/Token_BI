# Token BI v1.2.8

## 存储重置

- 主额度成功但到期明细暂时未返回时，不再立即抹去可用的近期记录。仅同一账号、次数一致、条目未到期且明细不超过 15 分钟时保留，并标注“上次记录”。
- 明细更新时间不随主额度同步或 App 重启延长；账号变化、次数变化、过期或超出保留窗口后不复用，不拼接新旧列表。
- 明细请求最多等待 5 秒，沿用后台刷新周期；不能取得有效明细时显示“到期时间暂未同步”，手动刷新会区分主额度和明细状态。

## 运行效率与稳定性

- 按文件版本缓存已验证的账号配置，减少频繁轮询中的重复读盘、解析与校验；外部替换、损坏和删除仍会被检测，异常时暂停接入。
- 额度卡及存储重置数据未变化时复用界面节点，倒计时和变化后的显示继续正常更新。
- 额度快照与服务运行状态共用私有权限的原子写入，写入失败保留上一个完整文件；增强异常 JSON、无效编码和非法端口的容错。
- 删除无生产调用的旧同步入口和转发包装，统一通过同步协调器处理并发、超时及退出后的迟到结果。
- 不增加生产依赖、后台进程或上游高频轮询，保留 OAuth > CLI RPC > WKWebView 优先级及共享 Python 运行库。

## 升级说明

- macOS 11 及以上、Apple Silicon；仍为 ad hoc 签名、未公证。
- 提供 DMG、签名更新归档与版本清单，沿用原 Updater 密钥；在设置中检查并确认更新后，安装并重启生效。
- 保留用户数据与 Token BI 接入状态，不删除或退出 Codex、CLI 及网页账号。
- 存储重置明细依赖上游接口实际返回，不能保证每次同步都有到期时间；局部读盘和渲染优化不代表整体启动或网络同步按相同比例提速。
