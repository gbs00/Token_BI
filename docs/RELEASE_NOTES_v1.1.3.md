# v1.1.3 - 账号一致性、同步恢复与局域网稳定性

本次更新聚焦长期常驻使用中的账号正确性、断网恢复和副屏连接稳定性，保持 OAuth > CLI > Web 的单账号读取顺序。

## 更新内容

- 修复账号已切换、看板却混用上一账号额度的问题；只有当前账号的有效额度才会提交，身份不匹配的旧缓存会失效。
- 为 OAuth、CLI 和浏览器采集增加截止时间，修复响应不完整或请求悬挂导致同步长期阻塞的问题。
- 看板请求超时后恢复轮询，网络恢复、重新显示页面时主动更新；迟到的旧请求不会覆盖新数据。
- 修复同步失败仍提示成功的问题，明确区分服务运行、服务健康和额度是否更新成功。
- 账号管理、登录退出及运维接口仅允许本机访问；副屏仍支持查看额度和手动同步。
- 退出账号后暂停 Token BI 接入，直到再次点击登录；不会退出或修改 Codex App / CLI 的登录凭据。
- 进程停止前核验身份，避免过期 PID 或端口复用导致误停其他程序。
- 主服务同时支持 IPv4 / IPv6，修复部分 `.local` 入口优先使用 IPv6 时无法访问的问题；网络切换后更快更新局域网入口。
- 增加应用单实例保护，并将开发构建目录设为不索引，减少重复控制台和构建副本被 Spotlight 收录的问题。

## 下载与升级

- 下载 `Token.BI_1.1.3_aarch64.dmg`，适用于 Apple Silicon Mac。GitHub 会将本地构建文件名中的空格转换为点号，校验文件使用实际下载名称。
- 退出旧版 Token BI，将新版替换到“应用程序”后重新打开。无手工数据迁移，账号记录和运行数据保留。
- 同时提供 `.sha256` 文件供校验。未配置自动更新签名，本版本通过 DMG 手动升级。

## 验证与限制

- 本地 Python 回归 210 项通过，Rust/Tauri 测试 5 项通过；包含浏览器超时恢复、账号竞态与接口访问边界测试。
- App 与 DMG 构建、深度签名校验及镜像挂载通过；安装后的控制台和主服务启停、OAuth 同步、本机 IPv4/IPv6 看板访问验证通过。
- 使用 ad hoc 签名，尚未完成 Apple Developer ID 签名及公证，首次安装可能出现 Gatekeeper 提示。
- `.local` 仍依赖 Bonjour/mDNS 和 Wi-Fi 设备互访；不支持时请使用控制台的局域网 IP 备用二维码。
- 浏览器驱动完全阻塞时不会无限堆积采集线程，但可能仍需重启主服务。iPhone/Safari 实机效果需继续验收。
- 发布由本地构建与验证完成，GitHub Actions 发布流水线保持停用。
