# Token BI v1.2.3

## 本次修复

- **更新与退出更安全**：必须确认后台停止成功、控制进程退出且端口释放才安装更新；失败保留管理信息并反馈原因，不强行结束不属于本实例的服务。
- **账号与额度保持一致**：同步前检测本地 OAuth 身份变化；切换账号后即使网络失败，也不显示旧账号额度。同账号短暂断网仍保留最近成功数据。
- **CLI 发现更可靠**：补充 Finder 启动环境下 Homebrew、用户本地安装和 Codex.app 的 CLI 路径识别，诊断与采集使用同一规则。
- **本地通信不受代理干扰**：控制服务、主服务及浏览器调试端口之间的 HTTP 请求走回环直连；外部额度请求的代理能力保持不变。
- **错误提示更准确**：本机无 OAuth／CLI 时，不再用“未安装”掩盖 Web 兜底的网络、限流、页面变化等真实错误。
- **失联服务可重试恢复**：不再把“进程存在”当作“服务正常”，重试先安全停止失联的自有进程再启动；启动或清理失败保留 PID 和运行记录。
- **精简失效开发入口**：mock 预览改用独立样例服务，不再改写真实账号配置；删除旧种子脚本、无人调用的独立浏览器抓取和相关配置。

正常 OAuth > CLI > Web 优先级、刷新频率、额度计算、菜单栏交互及 Web 看板布局保持不变，无新增依赖或账号数据迁移。

## 升级方式

1. v1.2.1／v1.2.2 用户：进入菜单栏面板的「设置」检查更新，下载后确认「重启完成更新」。
2. v1.2.0 及更早版本：下载 DMG，退出旧 App 后替换应用程序目录中的 Token BI.app。
3. 升级保留账号和设置，重启期间副屏连接会短暂中断。安装遇到残留服务提示时，先退出对应实例或恢复服务后重试。

新版停止确认逻辑从安装 v1.2.3 后生效；旧版本升级本次时仍使用旧版自己的安装流程。需要稳妥手动更新时，可先显式退出旧 App，再使用 DMG 替换。
