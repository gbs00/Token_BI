# Token BI v1.2.7

## 账号与缓存恢复

- 同账号重新登录时保留最后成功的额度与重置时间；断网、失败或取消不再清空已有数据。退出 Token BI 和不同账号的隔离规则保持不变。
- 修复短邮箱重复脱敏导致重启后丢失额度缓存的问题，兼容历史缓存；有稳定账号身份标识时不再用显示文字判断是否换号。
- 账号配置损坏时保留原文件、暂停接入，并提示通过登录恢复；网页会话配置仅在用户主动登录时修复。
- 配置采用私有权限和原子写入。不删除 Codex、CLI 或官方网站登录凭据，不混用不同账号的数据。

## 后台开销与日志

- 菜单栏内环和普通面板改为读取轻量状态，地址查询和日志读取只在二维码、诊断页按需执行。
- 地址查询增加超时限制。额度同步频率、OAuth 优先级及 WKWebView 按需启动保持不变。
- 控制服务启动不再对绑定地址查询反向 DNS，避免 DNS/mDNS 异常时阻塞本地监听初始化；预览及相关隔离测试共用同一实现。
- 后台日志按每份 5 MiB、2 份备份轮转，关闭重复的正常访问日志；启动异常和标准错误仍保留。
- 改善的是轮询开销与日志占用，不宣称整体启动、内存或耗电按相同比例改善。

## 工程验证

- 新增独立的 PR/main 只读回归检查，修正发布流程的开发依赖安装与 CI 临时目录初始化。
- Rust 工具链固定为本轮验证的 1.95.0，CI 与本地发布使用相同的格式和静态检查规则。
- 继续使用单套共享 Python 运行库，不增加生产依赖，不重新引入 Playwright/Node。
- 本机隔离测试覆盖账号恢复、离线缓存、同账号校验、轻量接口访问限制、二维码与诊断交互及日志容量限制。

## 升级说明

- macOS 11 及以上，Apple Silicon；仍为 ad hoc 签名、未公证。
- 提供 DMG、签名更新归档和 `latest.json`，沿用现有 Updater 密钥。已安装 1.2.1 及以上版本可在设置中检查更新，确认安装后重启生效。
- 保留用户数据和账号接入状态，不自动退出 Codex、CLI 或网页账号。
- 旧 macOS、长期会话过期、第三方 SSO 及跨设备网络切换仍需继续扩大实机验收。
