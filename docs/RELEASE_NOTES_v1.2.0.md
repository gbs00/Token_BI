# Token BI 1.2.0

日期：2026-09-13。

## 主要更新

- **菜单栏常驻**：以 311px 宽的紧凑面板取代桌面大控制台，点击菜单栏图标即可查看账号、额度和重置时间。收起面板不会停止副屏同步，明确退出 App 才停止本实例启动的服务。
- **扫码连接副屏**：局域网服务自动启动；二维码默认使用 LAN 地址，也可切换固定 `.local` 入口、复制链接或打开看板。
- **横屏优先自适应**：依据浏览器可见区域分配卡片与圆环空间，支持手机、平板、桌面，以及单/双额度与横竖屏切换。保留重置时间字号、旧 Safari 回退路径和用户主动缩放。
- **展示修复**：修正首次展开尺寸、原生圆角裁剪以及 100% 数字与百分号的排版层级，额度颜色仍按统一阶梯显示。

## 稳定性与精简

- 启动路径移除同步浏览器探测；仅实际使用 Web 兜底时恢复已有会话，OAuth / CLI 优先级保持不变。
- 手动刷新只向后端协调器发起一次当前账号请求，不再逐个遍历历史账号；保留后台定时同步、并发合并、超时与退避。
- 主服务短暂失联时保留同账号的旧额度并提示异常；暂停账号接入后不回填旧数据。服务停止后提供重试入口。
- 菜单栏扫码请求保存至页面就绪，避免首次点击失效。
- 状态轮询减少重复查询，日志摘要读取量封顶 64 KiB；删除相关无用包装及重复分支。
- 安装包前端资源采用白名单，不携带设计演示页与示例数据模块。

## 验证

- Python 全量回归 311 项、JavaScript 7 项、Rust 11 项通过；包括 58 项 Chromium/WebKit 自适应布局测试及菜单栏异常恢复行为测试。
- Rust Clippy、格式检查、Python 依赖一致性检查通过。正式包内 control/backend 的隔离启动、版本、暂停账号接入、看板资源、二维码及退出清理通过；未访问真实凭据。
- App 深度签名、DMG 校验与只读挂载检查通过；挂载 App 版本为 1.2.0，shell SHA-256 与构建产物一致。本轮没有覆盖已安装 App。
- 上述自动化不等于 iPhone 5S 的旧 Safari 真机验收，也不能代替物理跨屏、睡眠唤醒和多日常驻测试。

## 安装与限制

- 下载 `Token.BI_1.2.0_aarch64.dmg`，适用于 Apple Silicon Mac。安装前从菜单栏退出旧 Token BI，再将新 App 拖入“应用程序”替换；用户账号配置与缓存目录保持不变。
- 安装后从菜单栏图标进入，不再默认打开大控制台窗口。
- DMG 为 ad hoc 签名，**未完成 Developer ID 签名和 Apple 公证**，macOS 可能给出安全提示。本版不提供自动更新或 Intel / Universal 包。
- `.local` 依赖路由器和设备的 mDNS 支持；不可达时使用 LAN 二维码。访客网络、设备隔离、防火墙或 Mac 休眠仍可能阻断访问。
- 本版不改变单账号定位；不修改或退出本机 Codex CLI 的凭据。局域网看板为可信网络内的只读展示，不应直接暴露到公网。
