经用户明确允许，通过本地 Playwright 测试新建 HTML。未再次访问被内置浏览器策略阻止的旧参考图片页面，也未操作真实 Token BI。

```sh

```

Chromium、WebKit 均通过以下场景：

- 首次提示出现、打开面板、刷新后不重复提示、重新演示。
- 后台发现更新、红点、进入设置、展开说明、立即更新。
- 下载中断与恢复后重试，返回额度后下载继续。
- 就绪后稍后安装，返回设置仍可重启，模拟更新后版本变化且红点消失。
- 无更新、断网检查失败与恢复后重试。
- 无效签名场景只有重新下载，不提供安装或绕过校验按钮；这是 UI 状态断言，不是真实密码学校验。
- 切换场景会取消旧的异步计时，不由上一场景回写错误状态。
- 扫码页、诊断信息、返回与 Escape 收起；断言所有图钉、开关入口已不存在。
- 点击外部、焦点移出、模拟窗口 blur 与页面隐藏时收起，菜单栏图标可再次打开或收起。
- 鼠标移出不关闭；收起后的检查和下载继续，结束不自动弹回。
- 1280 × 900、1024 × 768、390 × 844、339 × 800、320 × 700 五种视口；页面无横向溢出，面板不出屏，核心更新和稍后按钮不与底部操作重叠。
- 无页面 JS 异常、无缺失图片、无 HTTP/HTTPS 请求。

## 残余验证范围

- HTML 模拟不验证 macOS 原生窗口锚点、多屏、隐藏菜单栏、刘海屏或系统通知行为。
- blur 与 visibilitychange 是浏览器事件处理测试，其中隐藏状态由测试临时模拟；不代表已验证真实跨应用或 macOS 原生失焦行为，正式开发仍需实机验收。
- 未验证真实网络版本检测、Updater 下载、密钥、包签名、安装权限、进程停止/重启和副屏恢复。
- WebKit 是本机 Playwright 所带引擎，不等同于 iPhone 5s 的旧 Safari；本轮也未修改副屏网页。
- 代码精简与包体优化尚未执行，基线及候选项见 `../../PRD_v1.2.1.md`。
